{% comment %} Client-side pager. Params — always pass with `only`: label : what's being paged, for the accessible name ("cast", "crew"). Ships hidden and stays hidden unless static/js/theoria.js finds more items than one page holds — so with JS off, or on a film with fewer than ten people, there are no dead buttons on the page. Buttons rather than links because these change nothing about the document's address: there is no request, and no URL that would restore this state on reload. The counterpart to _pager.html, which is the server-side pager for result sets too large to send whole. {% endcomment %}
