{% comment %} Shared pagination control. Params — always pass with `only`: page_obj : a Django Page/Paginator page object. param : query-string key to write the page number under, e.g. "page". base_query : the other query params to preserve, already urlencoded and joined with `&`, no leading/trailing `&` — empty string if there are none. Built in the view with django.utils.http. urlencode rather than assembled here: a shared partial can't know which params any given page carries, and building it in Python avoids a stray trailing `&` or a bare `?q=&sort=` when the other params are empty. This is the *server-side* pager, for result sets too large to hand a browser whole (/movies/ is 1,215 rows, /people/ is 122,685). The movie page's cast and crew are paged in the browser instead — one film's credits are small enough to ship in full — see [data-paged] in static/js/theoria.js. {% endcomment %} {% if page_obj.has_other_pages %}
